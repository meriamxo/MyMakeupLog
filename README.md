# My Makeup Log

## Questions

1. Which makeup style takes me the longest to complete?
2. Do I spend more time doing my makeup for certain occasions?
3. Which makeup style gives me the highest satisfaction rating?

## Data Dictionary

| Column | Type | Units | How I Record It |
|---|---|---|---|
| date | Date | YYYY-MM-DD | Date of the makeup session |
| makeup_type | Text | Category | Natural, soft glam or full glam |
| time_spent_minutes | Integer | Minutes | Measure with a timer |
| products_used | Integer | Number of products | Count distinct products used |
| occasion | Text | Category | College, work, going out or home |
| satisfaction_rating | Integer | Scale of 1 to 5 | Rate my finished makeup look |

## Description of the Project

For this assignment, I have chosen to track my personal makeup habits. I enjoy doing my makeup everyday and I want to find out how my makeup routine changes depending on the occasion and the type of look I choose.

Each time I do my makeup, I will record the style, how long it takes, the number of products I use, the occasion, and how satisfied I am with the result.

I will collect the data myself and record it in a CSV file. I will then use Python to analyse the results and create charts.

## Data Collection

I will measure the time using a timer and count the different products I use. I will rate each finished look from 1 to 5.

I will record at least 20 real makeup sessions and regularly update the CSV file on GitHub. I will not invent data for missed days.
